# 베이츠 재번역 작업 (VIII장부터)

『The Harmony of the Divine Attributes』(1674, 퍼블릭 도메인)의 한국어 본문(`src/ko/<장>.json`의 `ko` 배열)을
영어 원문에서 새로 번역해 오늘날 자연스러운 한국어로 바꾸는 작업입니다.
VII장에서 시범 번역을 블라인드로 비교했고, **Opus 5.5 번역이 채택**되었습니다 (`4994fd3`).
이 폴더의 지시서와 도구는 그 방식을 그대로 옮긴 것입니다.

## 반드시 지킬 것

- **`main`에 푸시하면 곧바로 배포됩니다** (GitHub Pages). 사용자가 아이폰에서 매일 읽습니다.
- **I–VI장(`1`–`6`)과 서문(`p`)은 건드리지 않습니다.** 형광펜이 한국어 글자 위치에 묶여 있어서, 본문을 바꾸면 형광펜이 어긋납니다.
- **`ko` 배열만 바꿉니다.** `title_ko`, `gist`, `argument_ko`, `notes`는 그대로 둡니다.
- **문단 수와 주석 표지(`{{s6}}` 등)는 절대 바꾸지 않습니다.** `validate.py`가 확인합니다.
- 성경 인용은 번역가가 직접 옮긴 문장이어야 합니다. 개역개정·새번역·새한글·우리말성경 같은 저작권 있는 한국어 성경 문장을 베끼지 않습니다.
- 다른 브랜치(`seojae-v1`, 서재 앱 개발 중)는 건드리지 않습니다.

## 진행 순서 (장마다 반복)

순서: `8` → `9` → … → `23`. 한 장씩 끝내고 푸시합니다.

1. 작업 묶음 만들기
   ```bash
   python3 tools/retrans/slice.py 8 /tmp/retrans/8
   ```
   `/tmp/retrans/8/`에 그 장의 영어 원문, 지금 한국어, 주석 요약, 어조 견본, 지시서가 생깁니다.
2. 번역 맡기기: **Opus 서브에이전트 한 명**에게 `/tmp/retrans/8/PROMPT.md`를 그대로 줍니다.
   장마다 새 서브에이전트를 쓰세요 (앞 장 내용이 쌓이지 않게).
3. 검증
   ```bash
   python3 tools/retrans/validate.py 8 /tmp/retrans/8/out.json
   ```
   마지막 줄이 `OK`여야 합니다. `WARN`은 원문과 대조해 정당하면 둡니다.
4. 반영과 빌드
   ```bash
   python3 tools/retrans/apply.py 8 /tmp/retrans/8/out.json
   python3 build.py
   ```
   `git diff --stat`에서 `src/ko/8.json`의 `ko` 줄 수만 바뀌었는지 확인합니다.
5. 커밋과 푸시: `src/ko/8.json`과 `index.html`만 커밋합니다.
   커밋 메시지에 번역가가 보고한 **기존 번역의 오역**과 **원문 파일의 오식 의심**(예: VII장 "a dear way" → "clear way")을 적습니다.

## 사용량

- 첫 장(VIII)을 끝내면 **멈추고** 사용자에게 알립니다. 사용자가 크레딧 잔액을 확인한 뒤 계속할지 정합니다.
- 참고: VII장(영어 5,225단어) 시범 번역은 서브에이전트 하나당 약 16만~18만 토큰이 들었습니다. `slice.py`로 입력을 줄였으니 그보다 적어야 합니다.
